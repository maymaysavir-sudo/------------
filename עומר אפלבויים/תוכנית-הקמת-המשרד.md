# תוכנית הקמה וסדר — משרד עו"ד עומר אפלבויים

> נכון ל-2026-06-17. מנהלת התהליך: מאיסה. מצב נוכחי: המשרד פתוח ~4 חודשים, ~30 לקוחות, ללא תשתית מסודרת.
> מסמך-על. כל שלב יקבל בהמשך קובץ נוהל (SOP) משלו תחת `עומר אפלבויים/nehalim/`.

---

## איך קוראים את המסמך
התוכנית בנויה ב-**8 שלבים**, מהבסיס ועד השיווק. כל שלב = רשימת פעולות עם תיבת סימון.
מה שדחוף ומה שאפשר לעשות מחר מסומן ב-🔴. מה שתלוי בגורם חיצוני (עודכנית, רו"ח, הלשכה) מסומן ב-⏳.

> ⚠️ **הערה חשובה**: כמה מהסעיפים נוגעים לחובות רגולטוריות של עו"ד (נאמנות, איסור הלבנת הון, אתיקה).
> אלה לא ייעוץ משפטי — הם רשימת תיוג לתפעול. את הניסוח המדויק יש לאשר מול עומר, רו"ח של המשרד, והלשכה.

- [ ] **תחום/י התמחות עיקריים** — מה ה-80% מהתיקים? (משפחה / נדל"ן / מסחרי / נזיקין / פלילי / עבודה...).
      זה קובע את תבניות המסמכים, את השיווק, ואת סוג הלקוח.
- [ ] **מבנה משפטי של העסק** — עוסק מורשה / חברה (עו"ד יחיד מול חברת עו"ד). משפיע על מס, חשבוניות וביטוח. → לאשר מול רו"ח.
- [ ] **מותג ושם** — "משרד עו"ד עומר אפלבויים" / שם מסחרי? סלוגן? לוגו?
- [ ] **תקציב חודשי לתשתית** — תוכנות, שיווק, מנוי. נגזור ממנו את הבחירות בכל שלב.
- [ ] **יעד 12 חודשים** — כמה לקוחות/הכנסה רוצים? כמה עובדים? זה מגדיר את קצב הבנייה.

## שלב 1 — תשתית דיגיטלית בסיסית 🔴
הבסיס שהכול יושב עליו. אפשר להתחיל מחר.

### 1.1 דומיין ומייל מקצועי
- [ ] לרכוש **דומיין** למשרד (למשל `appelboim-law.co.il` / `omerlaw.co.il`). דרך רשם ישראלי (ISOC) או GoDaddy.
- [ ] להקים **Google Workspace** (או Microsoft 365) על הדומיין — לא Gmail פרטי. עלות ~₪25–50 למשתמש/חודש.
      → נותן מייל מקצועי, יומן, Drive, Meet, ומקום מסודר לעובדים עתידיים.
- [ ] להגדיר כתובות: `omer@`, `office@` / `info@` (כתובת המשרד הכללית שמאיסה מנהלת).
- [ ] **חתימת מייל אחידה** לכל המשרד: שם, תפקיד, טלפון, כתובת, לוגו, והערת סודיות בתחתית.
- [ ] להעביר התכתבויות קיימות מהמייל הפרטי של עומר לכתובת החדשה (forwarding + הודעת "כתובתנו החדשה").

### 1.2 טלפון ותקשורת
- [ ] **מספר עסקי** נפרד (קו / VoIP / מספר וירטואלי). לא הנייד הפרטי של עומר.
- [ ] **WhatsApp Business** למספר המשרד — עם הודעת פתיחה, שעות מענה, ותפריט קצר.
- [ ] להחליט מי עונה ראשון לפניות (מאיסה?) ומה ה-SLA — תוך כמה זמן חוזרים ללקוח.

### 1.3 זהות מותגית
- [ ] **לוגו** (מעצב/פרילנסר) + קובצי מקור.
- [ ] **נייר מכתבים (letterhead)** דיגיטלי לתבניות מסמכים.
- [ ] **כרטיס ביקור** דיגיטלי + מודפס.

## שלב 2 — מערכות הליבה ⏳🔴
הלב התפעולי. עודכנית מתחברת בעוד שבוע — נתכונן אליה מראש.

### 2.1 עודכנית — תוכנת ניהול תיקים ⏳ (חיבור בעוד שבוע)
**להגיע מוכנים ליום ההטמעה.** רשימת הכנה:
- [ ] לרכז את **30 הלקוחות הקיימים** בקובץ אחד (גיליון): שם, ת"ז/ח"פ, טלפון, מייל, סוג תיק, סטטוס, יתרת שכ"ט.
- [ ] להגדיר מול עודכנית: **מספור תיקים אחיד**, שדות חובה, ושלבי תיק (סטטוסים).
- [ ] לוודא שהמערכת תומכת ב: **יומן מועדים/התיישנות**, מעקב שעות, מסמכים, וחיבור לחשבוניות.
- [ ] לשאול את נציג עודכנית: האם יש **אינטגרציה ל-u-pay** ול-Google Workspace? ייצוא נתונים? גיבוי?
- [ ] לקבוע **הדרכה** לעומר ולמאיסה + מי המשתמש-על.
- [ ] להעלות את 30 הלקוחות למערכת ביום ההטמעה (migration).

### 2.2 u-pay — חשבוניות וגבייה 🔴
- [ ] להשלים הקמת חשבון u-pay על שם העסק (פרטי עוסק/חברה, חשבון בנק).
- [ ] להגדיר **תבנית חשבונית** עם לוגו ופרטי המשרד.
- [ ] לוודא תאימות ל**מספרי הקצאה** (חוק חשבוניות ישראל) — לחשבוניות מעל הסף שדורש אישור רשות המסים. → לאשר מול רו"ח.
- [ ] לחבר אמצעי גבייה: אשראי / העברה / הוראת קבע, ולהגדיר מי מנפיק חשבונית ומתי.
- [ ] **כלל ברזל**: כל תקבול → חשבונית/קבלה מיידית. בלי "אחר כך".

### 2.3 ענן וניהול מסמכים 🔴
- [ ] **מבנה תיקיות אחיד** ב-Google Drive: `לקוחות/<מספר תיק> <שם>/` עם תתי-תיקיות קבועות (כתבי בי-דין, חוזים, התכתבות, חשבוניות).
- [ ] **מוסכמת שמות קבצים**: `YYYY-MM-DD_סוג-מסמך_שם-תיק`.
- [ ] **גיבוי** — לוודא שה-Drive מגובה וש-2 אנשים לפחות בעלי גישה.
- [ ] **כלל**: שום מסמך לקוח לא יושב על שולחן עבודה פרטי. הכול בענן, בתיק הנכון.

### 2.4 יומן וניהול מועדים 🔴 (קריטי לעו"ד)
- [ ] יומן Google Workspace משותף לעומר + מאיסה.
- [ ] **מערכת תזכורות למועדים קריטיים**: דיונים, הגשות, התיישנות, חידוש ייפויי כוח — עם התראה כפולה (שבוע + יום).
      → אובדן מועד = חשיפה לתביעת רשלנות. זה הסיכון מספר 1 במשרד לא מסודר.
- [ ] להחליט: המועדים יושבים בעודכנית, ביומן, או בשניהם מסונכרנים.

### 2.5 CRM / מעקב פניות 🔴
- [ ] טבלת/מערכת **lead tracking**: כל פנייה חדשה → מקור, תאריך, סטטוס (חדש / נקבעה פגישה / הצעה / נסגר / אבד).
      → מאפשר למדוד מאיפה מגיעים לקוחות (קריטי לשלב השיווק).

## שלב 3 — רגולציה, אתיקה וניהול סיכונים ⚠️
מה שמבדיל משרד מקצועי ממשרד שחשוף לצרות. לאשר כל סעיף מול עומר/הלשכה/רו"ח.

- [ ] **חברות בלשכת עורכי הדין** בתוקף + תשלום אגרה שנתית.
- [ ] **ביטוח אחריות מקצועית** בתוקף (לרוב דרך הביטוח הקולקטיבי של הלשכה) — לוודא כיסוי מתאים להיקף.
- [ ] **חשבון נאמנות / פיקדונות לקוחות** נפרד מחשבון המשרד — לכספים שמתקבלים עבור לקוח. → חובה לפי כללי הלשכה.
- [ ] **נוהל איסור הלבנת הון**: זיהוי ואימות לקוח (תעודה מזהה), "הכר את הלקוח", ותיעוד — לפי צו עוה"ד. תבנית טופס זיהוי בכל תיק.
- [ ] **בדיקת ניגוד עניינים** לפני קבלת כל לקוח חדש — מול רשימת הלקוחות הקיימת.
- [ ] **הסכם שכר טרחה בכתב** חתום בכל תיק — לפני תחילת עבודה.
- [ ] **שמירת סודיות וחיסיון עו"ד–לקוח** — הסדרת הרשאות גישה, ונספח סודיות לכל עובד עתידי.
- [ ] **הגנת הפרטיות** — אבטחת מאגר פרטי הלקוחות (סיסמאות, גישה מבוקרת), בהתאם לחוק.

## שלב 4 — תהליכי עבודה ותבניות (SOP) 🔴
כאן נכנס ה"סדר" האמיתי. כל תהליך נכתב פעם אחת — וחוזרים עליו תמיד אותו דבר. זה גם מה שיאפשר לקלוט עובדים בקלות.

### 4.1 תהליך קליטת לקוח (Intake) — מפנייה לתיק פתוח
1. פנייה נכנסת → נרשמת ב-CRM (מי, מקור, נושא).
2. שיחת סינון קצרה → האם זה תחום שלנו? ניגוד עניינים?
3. קביעת פגישת ייעוץ (בתשלום/חינם — להחליט).
4. הצעת שכר טרחה → **הסכם שכ"ט חתום**.
5. **טופס זיהוי לקוח** (איסור הלבנת הון) + **ייפוי כוח**.
6. פתיחת תיק בעודכנית + תיקיית Drive + רישום מועדים.
- [ ] לכתוב את התהליך כ-SOP אחד, עם מי-עושה-מה (עומר / מאיסה).

### 4.2 ערכת תבניות מסמכים (להכין פעם אחת)
- [ ] הסכם שכר טרחה
- [ ] ייפוי כוח (כללי + ספציפי)
- [ ] טופס זיהוי לקוח (הלבנת הון)
- [ ] מכתב פתיחה ללקוח / מכתב סיום טיפול
- [ ] תבנית מכתב דרישה / התראה
- [ ] תבנית הצעת מחיר
- [ ] אישור קבלת מסמכים
- [ ] checklist סגירת תיק (ארכוב + חשבונית סופית + מכתב סיום)

### 4.3 מעקב שוטף
- [ ] **ישיבת תיקים שבועית** קצרה (עומר + מאיסה): מה דחוף, מה תקוע, מועדים השבוע.
- [ ] **מעקב שעות/עבודה** בכל תיק → בסיס לחיוב ולתמחור עתידי.
- [ ] **מעקב גבייה**: אילו חשבוניות פתוחות, מי חייב, מתי לשלוח תזכורת.

## שלב 5 — כספים והנהלת חשבונות 🔴
- [ ] **הפרדה מוחלטת** חשבון בנק עסקי ↔ פרטי ↔ נאמנות.
- [ ] **רואה חשבון / יועץ מס** קבוע — אם אין, לסגור. הוא מאשר את כל סעיפי המס/חשבוניות במסמך הזה.
- [ ] תזרים חודשי בסיסי: הכנסות (u-pay) מול הוצאות (תוכנות, שכ"ד, אגרות, ביטוח).
- [ ] תיוק הוצאות מסודר לרו"ח (קבלות חשבוניות ספקים) — תיקייה ייעודית ב-Drive.
- [ ] לעקוב אחרי **דיווחי מע"מ ומקדמות מס** במועד (דרך רו"ח).
- [ ] לבנות **מחירון שירותים** בסיסי (פר סוג תיק / שעה / ריטיינר) — בסיס אחיד להצעות.

> 💡 כאן יש סינרגיה עם הסוכנים הקיימים: ניתן להקים בהמשך סוכן **הנהלת חשבונות** למשרד (בדומה ל-`adi` של סטודיו מאיסה).

## שלב 6 — שיווק ונוכחות 📣
⚠️ **שימו לב**: פרסומת של עו"ד בישראל **מוגבלת** בכללי לשכת עורכי הדין (פרסומת). אסור פרסום מטעה, התרברבות, או הבטחת תוצאות. הדגש על **מקצועיות, אמינות ותוכן ערכי** — לא על "הכי זול / מנצח תמיד". לאמת כל קמפיין מול הכללים.

### 6.1 נכסים דיגיטליים (הבסיס)
- [ ] **אתר אינטרנט** מקצועי: מי אנחנו, תחומי התמחות, יצירת קשר, ותוכן מקצועי. (Wix/WordPress להתחלה).
- [ ] **Google Business Profile** — קריטי. מופיע בחיפוש מקומי + מאפשר ביקורות.
- [ ] **LinkedIn** לעומר + עמוד למשרד — הערוץ הכי חזק לעו"ד (B2B, מוניטין, רשת).
- [ ] עמוד/נוכחות נוספת לפי הקהל (Facebook/Instagram אם הקהל פרטי, למשל דיני משפחה).

### 6.2 תוכן ומוניטין
- [ ] **מאמרים/טיפים מקצועיים** קבועים (בלוג/LinkedIn) בתחום ההתמחות — בונה סמכות וגם SEO.
- [ ] **איסוף ביקורות והמלצות** מ-30 הלקוחות המרוצים הקיימים → Google + אתר. (נכס הזהב שכבר יש לכם!)
- [ ] **רשת מפנים (referrals)** — קשר שיטתי עם רו"ח, יועצים, ועו"ד מתחומים משלימים. הערוץ הכי איכותי לעו"ד.
- [ ] **תיקי הצלחה / case studies** מנוסחים בזהירות (בלי לחשוף סודיות, בלי הבטחת תוצאות).

### 6.3 מדידה
- [ ] לכל לקוח חדש — לתעד ב-CRM **מאיפה הגיע**. אחרי 3 חודשים נדע איזה ערוץ עובד ונשקיע בו.

> 💡 סינרגיה: ניתן להפעיל סוכן **תוכן/סושיאל** למשרד (בדומה ל-`dana`) שמייצר פוסטים מקצועיים בהתאם למגבלות האתיקה.

- [ ] **מערכת הרשאות** מדורגת — לכל עובד גישה רק למה שצריך (Drive, עודכנית, מייל).

## ⚡ מה עושים השבוע — Quick Start
סדר עדיפויות מעשי ל-7 הימים הקרובים:

1. **שלב 0** — לסגור עם עומר את 5 החלטות היסוד (פגישה אחת).
2. **דומיין + Google Workspace + מייל מקצועי** (שלב 1) — אפשר היום.
3. **לרכז את 30 הלקוחות בגיליון אחד** — הכנה להטמעת עודכנית (שלב 2.1).
4. **להשלים הקמת u-pay + תבנית חשבונית** (שלב 2.2).
5. **מבנה תיקיות אחיד ב-Drive + יומן מועדים משותף** (שלב 2.3–2.4).
6. **לאמת מול עומר**: ביטוח מקצועי, חשבון נאמנות, אגרת לשכה בתוקף (שלב 3).
7. **לבקש המלצה/ביקורת** מ-3–5 לקוחות מרוצים (שלב 6.2) — נכס שיווקי מיידי.

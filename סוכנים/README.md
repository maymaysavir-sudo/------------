# סוכנים

**כל הסוכנים חיים כאן.** מוסכמה אחת, בלי יוצאי דופן:
קובץ הגדרה דק + מאגר ידע, עם `index.md` זול וקובץ-לכל-תובנה
(ראו [agent-architecture.md](../tmp/agent-architecture.md)).

## מבנה
```
סוכנים/<name>/
├── <name>.md          ← הגדרה (frontmatter + הוראות)
└── knowledge/
    ├── index.md       ← שער הידע (זול לקריאה)
    └── *.md           ← קובץ אחד = תובנה אחת
```

הקובץ האמיתי חי כאן; `~/.claude/agents/<name>.md` הוא symlink אליו, וכך הסוכן זמין
ל-Claude Code **בכל פרויקט**, לא רק כאן.

```
~/.claude/agents/adi.md  →  סוכנים/adi/adi.md
```

`~/.claude/agents/` מכיל **רק symlinks**. אם יש שם קובץ אמיתי, מישהו עקף את המוסכמה.
עורכים תמיד את הקובץ שכאן.
`claude global/` בשורש התיקיה הוא symlink ל-`~/.claude` — קיצור דרך לאותו מקום, לא עותק.

### להוסיף סוכן חדש
```bash
cd "/Users/my/Downloads/הקלוד של מאיסה"
mkdir -p "סוכנים/<name>/knowledge"
# כותבים את סוכנים/<name>/<name>.md ואת knowledge/index.md
ln -sfn "$PWD/סוכנים/<name>/<name>.md" ~/.claude/agents/<name>.md
```

### להסיר סוכן
```bash
rm ~/.claude/agents/<name>.md      # ה-symlink
rm -rf "סוכנים/<name>"              # ההגדרה + הידע
```

## איך קוראים לסוכן
פשוט מבקשים — "תני ל-dana רעיון לרילס", "adi, כמה הכנסתי החודש?", "netta, נסחי הודעת מסירה".
Claude מנתב לפי ה-`description` של כל סוכן.

## איך מוסיפים ידע
קובץ חדש ב-`knowledge/` בפורמט הקבוע (Core Insight / How It Works / Example / When to Use),
ושורה אחת ב-`index.md`. הסוכן **קורא** מהמאגר — הוא לא ממציא.

## חלוקת אחריות (כדי שלא ידרכו אחד לשני)
- מחיר ללקוחה → מהמחירון (netta שולפת). תמחור/מס עמוק → **adi**.
- עריכת תמונות → **rami**. תוכן לסושיאל → **dana**. שיחה 1:1 עם לקוחה → **netta**.
- crazy-eva כותבת סקריפט לרילס, dana מחזיקה את לוח התוכן ואת שפת המותג.

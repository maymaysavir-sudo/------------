# סוכנים — סטודיו מאיסה

ארבעה סוכנים בנויים לפי הארכיטקטורה החכמה (ראו [agent-architecture.md](../tmp/agent-architecture.md)):
**קובץ הגדרה דק + מאגר ידע**, עם `index.md` זול וקובץ-לכל-תובנה.

| סוכן | תפקיד | מתי קוראים לו |
|---|---|---|
| **rami** | עריכות / פוסט-פרודקשן | סינון חומרים, צבע, ריטוש, זרימת Lightroom, מסירה |
| **adi** | הנהלת חשבונות | הכנסות, הוצאות, מע"מ, סיכומים, חומר לרואה חשבון |
| **netta** | שירות לקוחות | הודעות, מענה אוטומטי, ליווי לקוחה מפנייה ועד מסירה |
| **dana** | סושיאל ותוכן | פוסטים, רילסים, לוח תוכן, שפת מותג, קריאייטיב |

## מבנה
```
סוכנים/<name>/
├── <name>.md          ← הגדרה (frontmatter + הוראות)
└── knowledge/
    ├── index.md       ← שער הידע (זול לקריאה)
    └── *.md           ← קובץ אחד = תובנה אחת
```
הקובץ האמיתי חי כאן; `.claude/agents/<name>.md` הוא symlink שהופך אותו זמין ל-Claude Code בפרויקט הזה.

## איך קוראים לסוכן
פשוט מבקשים — "תני ל-dana רעיון לרילס", "adi, כמה הכנסתי החודש?", "netta, נסחי הודעת מסירה". Claude מנתב לפי ה-`description` של כל סוכן.

## איך מוסיפים ידע
קובץ חדש ב-`knowledge/` בפורמט הקבוע (Core Insight / How It Works / Example / When to Use), ושורה אחת ב-`index.md`. הסוכן **קורא** מהמאגר — הוא לא ממציא.

## חלוקת אחריות (כדי שלא ידרכו אחד לשני)
- מחיר ללקוחה → מהמחירון (netta שולפת). תמחור/מס עמוק → **adi**.
- עריכת תמונות → **rami**. תוכן לסושיאל → **dana**. שיחה 1:1 עם לקוחה → **netta**.

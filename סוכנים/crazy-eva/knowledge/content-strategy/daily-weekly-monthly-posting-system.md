# Daily / Weekly / Monthly Content System

**Source**: https://www.instagram.com/reel/DTpydbvFeqg/?igsh=MWVuNm15OXF0cmxrcQ==
**Category**: content-strategy
**Added**: 2026-04-19

## Core Insight
Content work is most efficient when batched by cadence, daily actions stay light, weekly tasks batch medium work, monthly sessions handle the heavy lifting. Running it all daily burns you out.

## How It Works
**Daily:**
- Post 1 Story
- Post 1 Reel
- Write down ideas / capture inspiration

**Weekly:**
- Batch scripts (write multiple scripts at once)
- Study your post results
- Post 1 Carousel (optional)

**Monthly:**
- Do content research in bulk
- Batch film all content for the month
- Batch edit / review all edits

## Example
Eva uses this exact cadence for her own content operation, posting daily while only filming and scripting in weekly/monthly batches.

## When to Use
When setting up a sustainable content schedule. The daily habit is small (post + idea capture), the heavy lifting is batched to reduce context-switching.

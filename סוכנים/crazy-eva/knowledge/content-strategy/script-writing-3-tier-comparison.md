# How to Write a Script - 3-Tier Comparison

**Source**: https://www.instagram.com/reel/DV_BrTPjg2f/?igsh=MW1mOGF6NnphcGhhbw==
**Category**: content-strategy
**Added**: 2026-03-25

## Core Insight
A "bad → okay → best" comparison of scripting, hook, format, and strategy choices, showing exactly what separates low-performing from high-performing videos.

## How It Works
- **Scripting**, bad: freestyle; okay: bullet draft; best: intentionally scripted
- **Hooks**, bad: 1 hook; okay: 2 hooks; best: 3 hooks
- **Format**, bad: sit-down talking head; okay: one engaging format; best: multiple engaging formats
- **Hook source**, bad: original/made up; okay: 5x rule viral hooks; best: 1M+ view viral hooks in niche
- **Tactics**, bad: hashtags, trending audio, engagement hacks; best: none of that

## Example
A "best" video is intentionally scripted with 3 hooks stacked, filmed in multiple engaging formats, using hooks researched from 1M+ view videos in the niche, with no reliance on trending audio or hashtag tricks.

## When to Use
Before filming any video, use as a pre-production checklist to ensure every decision is at the "best" tier.

# 7-Figure Content Tool Kit - Category Framework

**Source**: https://www.instagram.com/reel/DWToQzSCVl2/?igsh=dG5xY2VhaHpodTcw
**Category**: content-strategy
**Added**: 2026-03-25

## Core Insight
A 7-figure creator's content stack spans 9 distinct tool categories, from research to lead gen. AI tools cover all of them, but every output still requires human quality control.

## How It Works
- **Research**, use AI tools to find topics, trends, and angles
- **Scripting**, use AI to draft video/post scripts
- **Image generation**, use AI for visuals
- **Scheduling & posting**, automate distribution
- **Repetitive content tasks**, automate manual production work
- **Lead generation**, tools to attract and capture leads
- **Lead magnets**, tools to create downloadable/valuable offers
- **Landing pages**, tools to build conversion pages
- **Carousels**, tools to design and produce carousel posts

## Example
The reel presents this as a visual "toolkit" list, each category shown on screen with a tool recommendation (visuals not captured in audio).

## When to Use
When auditing your own content workflow or building a creator tech stack, use these 9 categories as a checklist to identify gaps in your tooling.

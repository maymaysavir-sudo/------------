# מסגרת ביקורת BIO לאינסטגרם (human + SEO)

**Source**: GPT "ביקורת ביוגרפיה באינסטגרם" (2024)
**Category**: content-strategy
**Added**: 2026-07-26

## התפיסה
ביקורת bio בגישת StoryBrand: **בעל העסק = ה"guide" שמוביל את המבקר אל המטרה שלו** (לא הגיבור). ממזג אופטימיזציה/SEO עם טון אנושי חם שמניע אמון → בהירות → פעולה.

## מגבלות תווים (קשיח)
- **שם:** ≤ 64 תווים כולל רווחים.
- **ארבע השורות יחד:** ≤ 150 תווים כולל רווחים.

## 5 האלמנטים לביקורת (שאלה אנושית לכל אחד)
1. **שם** (SEO/נישה): מילות מפתח שגורמות למבקר להרגיש מיד "מצאתי את המומחה שמבין את הבעיה שלי".
2. **שורה 1** (הצהרת "אני עוזר" / הוק): את מי אתה עוזר, איזו בעיה, למי, באמפתיה.
3. **שורה 2** (שיטת עבודה / מעורבות): מסלול ברור ובר-השגה אל הפתרון.
4. **שורה 3** (אמינות): תעודות/תוצאות/סיפורי לקוח, או סיפור אישי אם אין. "מקצועי בלי להישמע יהיר."
5. **שורה 4** (CTA): דחיפות + תחושה מותאמת-אישית, "לחיצה על הלינק היא הצעד הראשון אל המטרה שלו".

## הפלט
ביקורת שממזגת SEO/אופטימיזציה עם טון אנושי חם. לכל שורה: מה עובד, מה חסר, וניסוח מוצע.

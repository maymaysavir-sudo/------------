# 8 Instagram Carousel Types - Slide-by-Slide Structure Outlines

**Source**: https://www.instagram.com/reel/DZH3ulkuuEc/
**Category**: content-strategy
**Added**: 2026-06-06

## Core Insight
There are 8 repeatable carousel formats, and every one follows the same skeleton: a **HOOK** slide, a body of slides that each pair short **Text** with a supporting **Visual**, and a final **CTA** slide. Pick the format that fits your message, then fill the blueprint, you never stare at a blank canvas.

## How It Works
Every format = HOOK → body slides (Text + Visual each) → CTA. The body changes per type:

1. **Tutorial**, HOOK → Steps #1-#7, each slide: *State the step* + *Breakdown in 1-2 lines* + *Visual of the step* → CTA. (How-to / process content.)
2. **Do's vs Don'ts (Right vs Wrong / Old vs New)**, HOOK → alternating DO and DON'T slides, each: *Text: DO or DON'T* + *Explain what to do / not do in 1-2 lines* + *Visual of it* → CTA. (Correction / contrast content.)
3. **Educational Tip / Hack** (6 slides), HOOK → *State Tip* → *Breakdown Tip in 1-2 lines (+visual of doing the tip)* → *Results: text + visual of the results* → CTA. (Quick win + proof.)
4. **Storytelling**, HOOK → body slides each: *Share one line of the story* + *Image from that time of your life* → CTA. (Personal narrative.)
5. **Transformation**, HOOK (*Visual: before & after image*) → Tip/Step #1-#5, each: *State the tip* + *Breakdown step in 1-2 lines* + *Visual of the tip* → CTA. (Result-led: "how I went from X to Y.")
6. **Problem / Solution**, HOOK → alternating Problem and Solution slides, each: *Text: Problem or Solution* + *Explain in 1-2 lines* + *Visual* → CTA. (Pain → fix.)
7. **Lists**, HOOK → Point #1-#5, each: *State the point* + *Breakdown in 1-2 lines* + *Visual of the point* → CTA. (Listicle.)
8. **Types**, HOOK → Type #1-#5, each: *State the type* + *Breakdown in 1-2 lines* + *Visual of the type on screen* → CTA. (Categorize/define a space, this very reel is a Types carousel.)

## Example
On screen each type is shown with 3-4 real high-engagement carousels (likes from ~280 up to ~75K) plus a grid blueprint. E.g. the Tutorial blueprint = HOOK box, then 7 step boxes (State Step / Breakdown 1-2 lines / Show Visual of Step), then a CTA box. The Storytelling examples ("Why do you have 500 transactions at Chipotle?") hit 16-22K likes using only one story-line + a personal image per slide.

## When to Use
When planning carousels and you want a proven container instead of inventing structure each time. Match format to intent: teaching a process → Tutorial; correcting a mistake → Do's vs Don'ts; a single hack → Educational Tip; personal credibility → Storytelling; before/after result → Transformation; pain-led → Problem/Solution; round-up → Lists; defining a category → Types. Drop your topic into the matching skeleton, keep body text to 1-2 lines per slide, and always pair text with a visual.

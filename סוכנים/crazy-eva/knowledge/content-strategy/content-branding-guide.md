# Content Branding System - Colors, Fonts, and Visuals

**Source**: https://www.instagram.com/reel/DT0jJSbjt00/?igsh=ZGdzeTkyMnhuano4
**Category**: content-strategy
**Added**: 2026-04-19

## Core Insight
Consistent branding doesn't require being aesthetic, it requires choosing 3 things (colors, fonts, visuals) once and repeating them across every video.

## How It Works
- **Step 1, Colors**: Choose 2-3 colors using one of these rules:
  - 60-30-10 rule
  - Golden ratio
  - Complementary colors
  - Analogous colors
  - Triadic colors
- **Step 2, Fonts**: Choose 2-3:
  - Primary font, for written hooks, bold/big text in video
  - Secondary font, regular captions
  - Accent font (optional), used sparingly for annotations
- **Step 3, Visuals**: Pick 2-3 consistent visual types to use throughout all videos:
  - Options: screenshots, screen recordings, B-roll, images, PNGs, charts, graphs

Once decided, apply these same 3 elements to every video, no re-deciding each time.

## Example
Eva shows a "big creator's" font system and visual types as real-world reference. Uses herself as an example, says even she (self-described "un-aesthetic") has a consistent style.

## When to Use
When starting a content brand or trying to establish a visual identity. Choose once, apply everywhere.

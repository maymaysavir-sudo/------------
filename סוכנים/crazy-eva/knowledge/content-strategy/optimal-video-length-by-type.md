# Optimal Video Length by Content Type

**Source**: https://www.instagram.com/p/DUThx5lEei1/
**Category**: content-strategy
**Added**: 2026-04-07

## Core Insight
Each content type has a natural optimal length. Going too long on a simple format wastes retention; going too short on a complex one loses value. These are guidelines, not hard rules, outliers always exist.

## How It Works
| Content Type | Optimal Length |
|---|---|
| Trending audio + viral text videos | 3-7 seconds |
| Q&A / ranking / rating videos | 15-30 seconds |
| Light educational (simple/repeatable structure) | 15-30 seconds |
| Storytelling videos | 45-60 seconds |
| Hyper educational / tutorials | 45-90 seconds |

## When to Use
At the scripting stage. Write your script, identify which type it is, then trim or expand to fit the right range. If a storytelling video is going over 60s, cut detail, don't pad; if a tutorial is under 45s, it probably needs more depth.

# Instagram Profile Optimization Framework

**Source**: https://www.instagram.com/p/DUEEpU0lg91/
**Category**: content-strategy
**Added**: 2026-04-07

## Core Insight
Your profile is the first thing potential followers see after clicking from a video. A properly structured profile converts viewers into followers. Each element has a specific function and format that maximizes searchability and conversion.

## How It Works
**Username:** Full name or business name (searchable, memorable)

**Profile picture:** Clear headshot with clean background

**Tagline (name field):** `[Name] | [Occupation/Title]`, this field is searchable on Instagram, so use keywords your ideal follower would search

**Bio:** 4-line framework:
1. Who you help / what you do
2. What result you deliver
3. Social proof or credibility line
4. CTA → single link

**Highlights:** Create highlights for these 5 categories (add relevant Stories to each): About, Results/Proof, [niche category], FAQ, [freebie/offer]

**Pinned posts:** Pin based on creator type, typically: best-performing TOFU video, best BOFU/lead video, and a personal/founder story

## When to Use
Onboarding a new client, profile audit before posting any content. Also use when an account is getting views but not converting to followers.

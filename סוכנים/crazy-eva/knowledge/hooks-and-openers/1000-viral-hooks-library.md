# 1,000 Viral Hooks - Full Reference Library

**Source**: PBL (Personal Brand Launch) by Ava Yuergens
**Resource file**: ../../../resources/1,000 Viral Hooks (PBL).pdf
**Category**: hooks-and-openers
**Added**: 2026-05-05

## Core Insight
A curated library of 1,000 fill-in-the-blank hook templates organized by category, each paired with a real Instagram/TikTok example link. Don't write hooks from scratch, pull a template, fill in your niche variables, and use the linked examples as visual references.

## How It Works
- Each hook is a template with `(insert X)` placeholders, swap in your niche, result, audience, or timeframe
- Categories: Educational, Comparison, Myth Busting, Storytelling, Authority, Day in the Life, Random
- Each template has a linked real-world example (Instagram/TikTok post) showing the hook in use
- Use the PDF as a brainstorming resource before scripting

## Hook Categories in the Library
- **Educational** (~500 hooks), teach something, how-to, step-by-step
- **Comparison** (~150 hooks), X vs. Y, before/after, old way vs. new way
- **Myth Busting** (~275 hooks), debunk a belief, "nobody tells you", "stop doing X"
- **Storytelling** (~265 hooks), personal story openers, journey hooks
- **Authority** (~220 hooks), credibility, results, expertise openers
- **Day in the Life** (~75 hooks), routine, lifestyle, behind-the-scenes openers
- **Random** (~50 hooks), miscellaneous high-performers

## Example
Template: `If I woke up (insert pain point) tomorrow, and wanted to (insert dream result) by (insert time) here's exactly what I would do.`

## When to Use
Whenever scripting a new video, open the PDF, pick a category that fits the content type, grab a template, and adapt. Especially useful when stuck on a hook or trying to test a new hook format.

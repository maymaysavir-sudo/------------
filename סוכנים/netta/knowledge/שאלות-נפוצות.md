# שאלות נפוצות — מענה אוטומטי (FAQ)
**Source**: תבניות שירות לקוחות.md (סעיף 7) · **Category**: faq · **Added**: 2026-06-13

## Core Insight
8 שאלות חוזרות על עצמן ב-90% מהפניות. תשובה אוטומטית מיידית לכל אחת = עומדים ביעד "90% מענה תוך שעה" בלי מאמץ, וכל תשובה מקדמת לשלב הבא.

## How It Works
מגדירים במענה האוטומטי של אינסטגרם/וואטסאפ. כל תשובה מסתיימת בשאלה (חוק הזהב):
- **כמה עולה?** → "3 חבילות שמתחילות מ-1,800 ₪. מתי האירוע, שאתאים לכן?"
- **כמה זמן הצילום?** → "שעה–שעתיים לפי חבילה, עד שמרגישים את הקסם 😊"
- **מתי מקבלים תמונות?** → "תוך כ-[X] שבועות, בגלריה דיגיטלית."
- **אפשר בחוץ?** → "בהחלט! קלאסי ומעלה כוללות לוקיישן חוץ."
- **מה ללבוש?** → "אשלח קובץ הכנה מפורט אחרי שנסגור — בקיצור: 2–3 לוקים שהבת אוהבת."
- **אתם בת"א?** → "כן, הסטודיו בתל אביב."
- **יש אלבום פיזי?** → "יש! אלבום קשיח והדפסות ממוסגרות."
- **איך סוגרים תאריך?** → "שולחים תאריך מועדף, ואני שומרת אותו עם מקדמה קטנה 😊"

## Example
מגיע "כמה זה עולה?" בשעה 23:00 → המענה האוטומטי שולח מיד את תשובת המחיר עם שאלת התאריך, והליד נשמר חם עד הבוקר.

## When to Use
להגדרה חד-פעמית במערכת המענה האוטומטי, ולעדכון כשמשתנים מחירים/זמני אספקה.

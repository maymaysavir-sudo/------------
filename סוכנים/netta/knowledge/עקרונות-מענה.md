# עקרונות מענה — שלושת חוקי הזהב
**Source**: תבניות שירות לקוחות.md (סעיף 8) · **Category**: principles · **Added**: 2026-06-13

## Core Insight
שלושה עקרונות סוגרים יותר לקוחות מכל ניסוח מושלם: **מהירות, שאלה בסוף, אישי לפני מחיר**. הם חשובים מ"מה" בדיוק כתבת.

## How It Works
1. **מהירות** — לענות תוך שעה כשאפשר. ליד "חם" מתקרר מהר; מענה מהיר מכפיל סגירות.
2. **תמיד שאלה בסוף** — כל הודעה נגמרת בשאלה שמקדמת לשלב הבא: תאריך? חבילה? לסגור תאריך?
3. **אישי לפני מחיר** — קודם שם הבת והתאריך, ורק אז מחיר. בונים יחס, לא זורקים מספר.

## Example
אמא שואלת "כמה עולה בוק?" → לא לזרוק מחיר יבש. במקום: "יש לי 3 חבילות שמתחילות מ-1,800 ₪, ואשמח להתאים לכן את הנכונה 💛 מתי האירוע מתוכנן ועל איזו אווירה חשבתן?" (מחיר + אישי + שאלה).

## When to Use
בכל הודעה יוצאת, ללא יוצא מן הכלל.

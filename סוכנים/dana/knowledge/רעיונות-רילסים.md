# רעיונות רילסים — בנק hooks שמביא לידים
**Source**: אסטרטגיית תוכן · **Category**: reels · **Added**: 2026-06-13

## Core Insight
רילס מביא לידים כשיש לו **hook ב-3 השניות הראשונות** שעוצר את האמא בגלילה, ו-**CTA ברור** בסוף. תמונה יפה בלי hook = נגללת.

## How It Works
**פורמטים שעובדים לבת מצווה:**
- **טרנספורמציה** — מהבת מגיעה ביישנית עד החיוך האמיתי בסוף. מפרק את "תצא קפואה".
- **רשימה מהירה** — "3 טעויות שאמהות עושות לפני בוק בת מצווה".
- **הצצה מאחורי הקלעים** — איך נראה יום צילום, כמה כיף וקליל.
- **שאלה-תשובה** — "כמה זמן לוקח?" / "מה ללבוש?" עם תשובה מהירה.
- **תוצאה + רגש** — קליפ קצר של בת מתרגשת מהתמונות שלה.

**מבנה קבוע:** Hook (3ש') → ערך/רגש (10–20ש') → CTA ("רוצה בוק לבת שלך? שלחי לי DM 💛").

## Example
Hook: "הבת שלך מתביישת מול מצלמה? זה בדיוק מה שאני אוהבת." → מראים תהליך שמוציא חיוך אמיתי → CTA לפנייה. מדבר ישירות לחשש המרכזי של האמא.

## When to Use
בכל בקשת רעיון/תסריט לרילס. בוחרים פורמט לפי עמוד התוכן ([[עמודי-תוכן]]) והחשש שרוצים לפרק ([[קהל-היעד]]).
